Reproduce local unit/render checks (jsonschema is an optional test dependency):
  python3 -m pip install PyYAML==6.0.1 jsonschema
  python3 -m unittest discover -s tests -v
  bash -n dpf-argo.sh

To reproduce full schema checks after configuring and rendering the package:
  curl -fsSL https://raw.githubusercontent.com/kubernetes/kubernetes/v1.34.0/api/openapi-spec/swagger.json -o /tmp/kubernetes-openapi.json
  python3 tools/validate.py rendered/platform.yaml --kubernetes-schema /tmp/kubernetes-openapi.json
Use the official schema for your actual target Kubernetes version.
